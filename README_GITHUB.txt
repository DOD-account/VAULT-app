MÉTHODE 1 : Via GitHub Desktop (Plus facile)
─────────────────────────────────────────────
1. Télécharger GitHub Desktop : https://desktop.github.com/
2. Installer et se connecter à votre compte GitHub
3. Cliquer sur "File" → "Add Local Repository"
4. Sélectionner le dossier contenant ces fichiers
5. Cliquer sur "Publish repository"
6. Choisir le nom : "vault-saas" (ou autre)
7. Ajouter une description
8. Publier !


MÉTHODE 2 : Via Ligne de Commande (Pour développeurs)
──────────────────────────────────────────────────────
Étape 1 : Créer un nouveau repository sur GitHub.com
  → Aller sur https://github.com/new
  → Nom : vault-saas
  → Description : Plateforme SaaS Expert Retraite
  → Public ou Private
  → NE PAS initialiser avec README (déjà créé)
  → Cliquer sur "Create repository"

Étape 2 : Dans votre terminal, aller dans le dossier des fichiers
  cd /chemin/vers/les/fichiers

Étape 3 : Initialiser Git
  git init

Étape 4 : Ajouter tous les fichiers
  git add .

Étape 5 : Créer le premier commit
  git commit -m "Initial commit - VAULT v1.0"

Étape 6 : Lier au repository GitHub
  git remote add origin https://github.com/VOTRE-USERNAME/vault-saas.git

Étape 7 : Pousser vers GitHub
  git branch -M main
  git push -u origin main

✅ Terminé ! Votre code est maintenant sur GitHub !


MÉTHODE 3 : Via GitHub Web (Drag & Drop)
─────────────────────────────────────────
1. Créer un nouveau repository sur https://github.com/new
2. Une fois créé, cliquer sur "uploading an existing file"
3. Glisser-déposer TOUS les fichiers (sauf node_modules)
4. Ajouter un message de commit : "Initial commit"
5. Cliquer sur "Commit changes"
