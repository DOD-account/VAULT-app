# VAULT - Système de Gestion Intégré

Application web de gestion avec 4 modules principaux :
- 📋 Profil
- 💼 Carrières
- 📈 Projections
- 📋 Demandes Caisses

## 🚀 Déploiement sur Netlify

### Option 1 : Drag & Drop (Le plus simple)

1. Allez sur [netlify.com](https://www.netlify.com)
2. Connectez-vous ou créez un compte gratuit
3. Glissez-déposez tout le dossier sur la zone de déploiement
4. Votre site sera en ligne en quelques secondes ! 🎉

### Option 2 : Via Git

1. Créez un repository sur GitHub/GitLab
2. Uploadez tous les fichiers du projet
3. Sur Netlify, cliquez sur "New site from Git"
4. Connectez votre repository
5. Laissez les paramètres par défaut
6. Cliquez sur "Deploy site"

## 📁 Structure du projet

```
vault-netlify/
├── index.html              # Page principale
├── vault-application.jsx   # Application React
└── README.md              # Ce fichier
```

## 🛠️ Technologies utilisées

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- Babel Standalone (pour compiler JSX dans le navigateur)

## 📝 Notes

- Aucune installation de dépendances nécessaire
- Tout fonctionne directement dans le navigateur
- Compatible avec Netlify, Vercel, GitHub Pages, etc.

## 🌐 Après le déploiement

Une fois déployé, vous obtiendrez une URL du type :
`https://votre-site.netlify.app`

Vous pourrez ensuite :
- Personnaliser le nom du site
- Ajouter un domaine personnalisé
- Configurer HTTPS (automatique sur Netlify)
