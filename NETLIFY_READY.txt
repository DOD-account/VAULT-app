┌─────────────────────────────────────────────────────────────────────────┐
│                      🆘 EN CAS DE PROBLÈME                               │
└─────────────────────────────────────────────────────────────────────────┘

PROBLÈME : Build échoue sur Netlify
SOLUTION : 
  1. Vérifier les logs de build
  2. S'assurer que toutes les dépendances sont dans "dependencies"
  3. Vérifier Node.js version (18 dans netlify.toml)

PROBLÈME : Page blanche après déploiement
SOLUTION :
  1. Vérifier la console navigateur (F12)
  2. Vérifier que public/_redirects existe
  3. Vérifier que netlify.toml est présent

PROBLÈME : Routes React donnent 404
SOLUTION :
  → Le fichier public/_redirects règle ce problème
  → Si absent, le créer avec : /*    /index.html   200

PROBLÈME : Les assets ne se chargent pas
SOLUTION :
  1. Vérifier le chemin dans vite.config.js
  2. Vérifier que dist/ contient bien les assets
  3. Clear le cache Netlify et redéployer
